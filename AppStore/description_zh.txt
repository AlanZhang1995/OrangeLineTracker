VTA 轻轨追踪 - Apple Watch 实时到站时间

再也不会错过列车！VTA Transit Tracker 将圣克拉拉谷交通局 (VTA) 轻轨的实时到站信息直接带到你的手腕上。

功能特点

• 实时到站时间
获取所有 VTA 轻轨站点的准确到站预测。精确显示下一班车还有几分钟到站。

• 支持全部三条线路
- 橙线 (Orange Line): Mountain View ↔ Alum Rock
- 蓝线 (Blue Line): Baypointe ↔ Santa Teresa
- 绿线 (Green Line): Old Ironsides ↔ Winchester

• 智能时间规则
专为通勤族设计的自动化功能。设置多条时间规则，让 App 根据时间自动切换站点和方向：
- 早上 7:30 自动显示去公司的站点及对应方向
- 下午 5:30 自动切换到回家的站点及对应方向
- 规则可随时启用/禁用
再也不用每天手动切换，抬腕即可看到当前需要的信息。

• 表盘小组件
将小组件添加到表盘，即时查看到站时间。支持圆形、矩形、内联和角落四种样式。
矩形会显示站点名和方向，圆形只有倒计时。建议先使用矩形确认时间规则工作正常后，再使用圆形小组件。

• 双语支持
完整支持中文和英文界面。随时在设置中切换语言。

• 智能刷新
根据列车距离智能调整刷新间隔 - 列车越近，刷新越频繁。
（这个功能没什么卵用，watchos限制了后台刷新时间15min，所以小组件其实也只能看个大概，习惯卡时间的用户建议打开app进一步确认）

• 自定义 API 密钥
使用你自己的免费 511.org API 密钥，避免限流问题。

适用人群

• VTA 轻轨日常通勤者
• 探索硅谷的游客
• 任何需要快速查看列车时间的人

数据来源

实时数据由 511.org SIRI API 提供，这是湾区公共交通信息的官方来源。

隐私保护

本应用不收集任何个人数据。所有偏好设置都存储在你的设备本地。
